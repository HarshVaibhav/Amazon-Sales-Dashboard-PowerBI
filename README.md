# Amazon Sales Dashboard — Power BI

> Interactive Power BI dashboard for sales, customer, product, payment, geographic, and operational analysis.

## Project Overview

This project analyzes Amazon sales data using **Power BI, Power Query, DAX, and data modeling**.

- Return Rate

## Key Insights

- Revenue reached **91.83M** across more than **100K orders**.
- Average Order Value was **918.26**.
- Credit Card was the highest revenue-generating payment method in the analysis.
- A relatively small group of products contributed a large share of revenue.
- Electronics and Home & Kitchen were among the stronger revenue-contributing categories.
- The dataset showed a low reported return rate of **2.83%**.
- Revenue displayed seasonal variation across the analyzed period.

## Business Recommendations

- Investigate products with elevated return rates.
- Optimize inventory for high-performing products ahead of peak demand.
- Analyze underperforming categories for targeted growth opportunities.
- Strengthen customer-retention initiatives to increase repeat purchases.
- Track profit margin alongside revenue to distinguish high-sales products from high-profit products.
- Compare state-level performance to identify scalable sales strategies.
