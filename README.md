# Amazon Sales Dashboard — Power BI

An interactive Power BI dashboard exploring sales, customers, products, payment methods, geography, and order operations in the selected Amazon sales dataset.

## Project Overview

The project uses Power BI to turn transaction data into a business-facing dashboard. It demonstrates data transformation, DAX measures, data modeling, visual design, and communicating findings through KPIs and charts.

## Dashboard Coverage

- Revenue and order volume
- Customer count and average order value
- Quantity sold and reported return rate
- Product and category performance
- Revenue by state
- Revenue by payment method
- Order-status distribution
- Revenue trends over time

## Tools and Skills

- **Power BI** — dashboard design and reporting
- **Power Query** — data preparation and transformation
- **DAX** — measures and KPI calculations
- **Data modeling** — organizing data for analysis
- **Business analysis** — interpreting trends and identifying follow-up questions

## Existing Findings

- Credit Card is identified as the highest revenue-generating payment method in the current analysis.
- A relatively small group of products contributes a large share of revenue.
- Electronics and Home & Kitchen are among the stronger revenue-contributing categories.
- The reported return rate is 2.83%.
- Revenue varies across the analyzed period.

Use these findings as dataset-specific observations, not as claims about Amazon's overall business.

## Business Questions to Explore

- Which products and categories contribute most to revenue?
- Which states have the strongest sales performance?
- How do payment methods compare by revenue?
- Which order statuses or products merit operational investigation?
- Does high revenue also correspond to stronger profitability? (Profit/cost data is needed to answer this reliably.)

## Dataset

Source: [Amazon Sales Dataset on Kaggle](https://www.kaggle.com/datasets/rohiteng/amazon-sales-dataset)

## Interpretation Notes

Revenue alone does not establish profitability. The current summary does not document product costs, so recommendations about margin or profit require additional cost data. KPI definitions and filters should be checked in the Power BI model before the values are used in a resume or interview.
